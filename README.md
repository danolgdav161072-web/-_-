# ⚡ ЭнергоПолис: Спаси колледж

Интерактивный экономический веб-квест и симулятор энергоменеджмента, разработанный специально для учащихся учреждений среднего специального образования (колледжей) Республики Беларусь. 

Проект подготовлен для участия в республиканском конкурсе **«Энергомарафон»** в номинации *«Геймификация в энергосбережении»*.

## 🎯 Суть и цели игры
Игрок выступает в роли главного энергоменеджера учебного корпуса. Стартовый бюджет составляет **10 000 белорусских рублей**. Задача — за несколько игровых уровней провести глубокую модернизацию здания, пережить аномальные зимние морозы (-30 °C) и не допустить коммунального банкротства.

**Ключевые образовательные особенности:**
* **Связь с нормативной базой РБ:** Задания опираются на требования Директивы Президента Республики Беларусь № 3, Санитарные нормы и правила (СанПиН РБ) и строительные нормы (СН 4.01.01-2019).
* **Экспресс-аудит на местах:** В процессе игры учащиеся отрываются от экрана, чтобы пересчитать светильники в реальной аудитории и проверить окна на наличие сквозняков.
* **Поисковый характер (Веб-квест):** Для принятия верных решений игроки самостоятельно ищут характеристики оборудования (светодиодные лампы ОАО «Брестский ламповый завод»), рассчитывают срок окупаемости (ROI) и анализируют графики ночного потребления энергии (АСКУЭ / Smart Grid).

## 🛠️ Технологии разработки
* **Платформа:** [Twine](https://twinery.org) (свободное ПО с открытым исходным кодом для создания нелинейных интерактивных историй).
* **Формат истории:** Harlowe.
* **Формат сборки:** Автономный кроссплатформенный файл `index.html`, не требующий установки сторонних программ.

## 🚀 Как запустить игру
1. Перейдите по ссылке на веб-версию игры *(вставьте сюда вашу ссылку GitHub Pages после публикации)*.
2. Или скачайте файл `index.html` из этого репозитория и откройте его в любом современном браузере (Chrome, Safari, Яндекс.Браузер, Edge) на ПК или смартфоне.

## 📁 Структура репозитория
* `index.html` — скомпилированная рабочая версия компьютерной игры.
* `README.md` — описание проекта и инструкция по запуску.
